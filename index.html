ÉTAPE 01

Importe ton journal

Tu as déposé un seul fichier. Pour avoir toutes les statistiques (notes, coups de cœur, revisionnages, année, pseudo), il faut le ZIP en entier.

Comment obtenir mon export Letterboxd ?
  1. Connecte-toi sur letterboxd.com depuis un ordinateur (cette option n'existe pas dans l'application mobile).
  2. Clique sur ton pseudo en haut à droite, puis sur Settings (Paramètres).
  3. Ouvre l'onglet DATA, en haut de la page.
  4. Clique sur Export your data. Un fichier .zip du type letterboxd-pseudo-date.zip est téléchargé.
  5. Dépose ce fichier ici tel quel, sans l'ouvrir ni le décompresser. Il faut le ZIP en entier : il contient plusieurs fichiers (films vus, notes, journal, coups de cœur, profil) et chacun sert à une partie des statistiques.

ÉTAPE 02

Connecte les données cinéma

TMDB est la base de données de films qui fournit les durées, genres, acteurs et affiches. Il faut un compte gratuit et une clé personnelle, c'est l'affaire de 5 minutes.

Comment créer mon compte et trouver ma clé TMDB ?
  1. Va sur themoviedb.org/signup et crée un compte gratuit (pseudo, e-mail, mot de passe). Clique sur le lien reçu par e-mail pour valider ton adresse. Si tu as déjà un compte, connecte-toi.
  2. Une fois connecté, ouvre themoviedb.org/settings/api. Tu peux aussi cliquer sur ton avatar en haut à droite, puis Paramètres, puis API dans le menu de gauche.
  3. Si aucune clé n'existe, clique sur Créer (ou Demander une clé API), choisis Developer et accepte les conditions d'utilisation.
  4. Remplis le formulaire. Nom de l'application : Stats Letterboxd. Type d'utilisation : Personal (ou Other). Adresse internet : n'importe quelle adresse valide, par exemple https://example.com Résumé : Script personnel qui calcule mes statistiques de films à partir de mon export Letterboxd. Ajoute ensuite tes coordonnées (nom, adresse, téléphone) et valide.
  5. Reviens sur la page API : copie la valeur Clé API (32 caractères, lettres et chiffres). C'est elle qu'il faut coller ci-dessous. Le Jeton d'accès en lecture, beaucoup plus long, fonctionne aussi.
  6. Ne partage pas ta clé. Tu peux la régénérer à tout moment sur la même page si besoin.

La clé est gardée uniquement dans ce navigateur, sur cet ordinateur, et n'est envoyée qu'à TMDB. Décoche la case sur un ordinateur partagé : la clé enregistrée est alors effacée.

                                                  Défi entre cinéphiles

                                                  Compare tes statistiques avec celles d'un(e) ami(e) : compatibilité, duel en plusieurs manches, films à se conseiller et un jeu pour deviner ses notes. Chacun envoie sa « carte » à l'autre (par message, mail…), puis l'importe ici.
